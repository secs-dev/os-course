# FUSE

В данной лабораторной работе вы познакомитесь с технологией [libfuse](https://github.com/libfuse/libfuse). Она позволяет реализовывать файловые системы в userspace, что проще, чем разработка модуля ядра. Обратите внимание, что для данной библиотеки есть bindings для Python.

Подумайте, какие сервисы можно предоставлять через API файловой системы. Например, просмотр GitHub-репозиториев, объекты в СУБД, чаты в мессенджере.

Решите, что бы вы хотели реализовать и согласуйте это с преподавателем, после чего сделайте свою файловую систему.

Вы можете сгенерировать взаимодействие с внешним сервисом при помощи LLM. Сгенерированный код должен быть выделен в отдельный изолированный программный модуль. Обязательно отразите в отчете методику работы с LLM.
