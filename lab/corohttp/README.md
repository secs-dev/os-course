# HTTP Coroed

Вам дан простой фреймворк со stackful корутинами - [Coroed](https://github.com/vityaman-edu/coroed). Ваша задача -- добавить в него поддержку асинхронного ввода-вывода, на основе чего реализовать простой HTTP сервер.

## Async IO

Проблема: привычные read/write блокируют поток, что понижает эффективность сервера и нивелирует пользу корутин. Необходимо реализовать неблокирующий ввод-вывод, используя предоставляемый ОС API. С точки зрения корутины аналоги read/write должны быть привычными, "блокирующими". При вводе-ввыводе корутина должна переводиться в состояние ожидаения, а ее поток должна занять другая, готовая к исполнению.

Будьте осторожны при использовании функций из libc. Некоторые из них могут использовать thread local переменные, что из-за чего возникнут проблемы с вытесняющей многозадачностью через `alarm`.

## HTTP

Как только будет готов API для ввода-вывода, реализуйте простой HTTP сервер. Он должен отвечать на запрос `/hello/<name>` JSON-объектом с полем `message` и значением `<name>`.

## Benchmark

Реализуйте HTTP-сервер только через потоки (1 запрос — 1 поток). Разработайте тест производительности.Сравните результаты с coroed.
