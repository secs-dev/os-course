# CoroShed

Вам дан простой фреймворк со stackful корутинами - [Coroed](https://github.com/vityaman-edu/coroed). Ваша задача -- доработать планировщик задач.

Изначально в coroed планировщик хранит задачи в массиве. Из-за этого количество задач ограничено, а также планирование осуществляется нечестным способом. Реализуйте feedback планировщик задач.

Протестируйте свойства нового планировщика и сравните его с изначальной реализацией.
